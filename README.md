# Keys

Private list of environment keys, locked with a PIN in the browser.

- Systems: Vercel, GitHub, or a custom name. A key can belong to more than one.
- Service: Billing, Licence, Dev, or custom.
- Import an Excel or CSV file, or paste cells copied from Google Sheets.
- Columns: system, service, key name, secret.

Keys stay in this browser, encrypted with the PIN. A forgotten PIN cannot be recovered.
